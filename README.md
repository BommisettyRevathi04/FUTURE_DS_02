# FUTURE_DS_02 — Customer Retention & Churn Analysis

## 📌 Task Overview

This project is part of the Future Interns Data Science & Analytics Internship.

The objective of this task is to analyze customer data to identify churn patterns, retention trends, key retention drivers, and customer lifetime trends for a subscription-based business.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Dashboard
- Charts
- Data Analysis

## 📊 Project Deliverable

A customer retention and churn analysis dashboard was created to present important customer retention metrics, churn patterns, and trends in an interactive and easy-to-understand format.

## 🔍 Analysis

The dashboard focuses on:

- Customer churn patterns
- Customer retention trends
- Factors associated with customer loss
- Customer lifetime trends
- Key performance indicators

## 💡 Key Insights

The dashboard provides a visual overview of customer retention and churn performance and helps identify areas where customer loss can be reduced.

## 🎯 Recommendations

- Identify the customer segments with higher churn.
- Monitor retention trends regularly.
- Focus retention efforts on customers showing signs of potential churn.
- Use customer-level insights to improve retention strategies.
